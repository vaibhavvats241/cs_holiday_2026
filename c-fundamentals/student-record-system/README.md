# Student Record System in C

A menu-driven CLI application built in C during my summer break.

## Features
- Add multiple students
- Display all records
- Search student by name
- Find topper
- Save records to file
- Load records from file

## What I learned
- Structs and pointers to structs
- File I/O with custom | separator
- Menu driven programs using switch case
- Dynamic input handling with fgets and scanf
- Defensive programming with limit checks

## How to run
gcc student.c -o student
./student
